## 实际终端与视觉检查

`verify_inline_terminal.py` 使用实际 Windows 内联驱动、固定模拟模型和临时文件，验证读取与计划、/do 后连续修改→读取→搜索→最终答复，轮次与累计用量、Markdown、选择界面、主题、历史、退出和 console mode 恢复。驱动输出未包含备用屏幕或清空全屏指令，也无独立背景色或 dim。测试工具 PTY 启动外层 PowerShell 自身的清屏序列不属于应用驱动输出。鼠标测试通过真实输入驱动注入 SGR 事件，没有执行物理鼠标操作。

`preview_agent.py` 生成真实 Textual compositor 的 `agent-plan`、`agent-loop`、`agent-loop-narrow` JSON/SVG，PNG 由单元格数据绘制。已查看宽屏与窄屏效果；窄屏状态不再重复历史快捷键提示。保留原生背景、浅绿图标、正常前景、简洁工具行与输入分隔线。预览中的 Token 数来自模拟服务固定统计，不是实际请求账单。

## 模块边界

- `agent.py`：与 SDK、Textual、Rich 无关的循环、流式收集器、模式与用量累计。
- `conversation.py`：保留 reply/ask 和历史快照入口，委托同一 AgentLoop。
- `tools/execution.py`：只读分批并发、副作用顺序与结果/取消收尾。
- `messages.py`：应用自有事件与消息类型；协议原生数据仍由适配器保留。
- `tui.py` / `cli.py`：消费同一事件流，界面不负责模型工具循环。
