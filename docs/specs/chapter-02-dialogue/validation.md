## 2026-10-11：改用终端原生滚动历史

用户进一步反馈同一终端多次启动后，滚轮只能作用于最新应用。原因是开启鼠标报告把滚轮送入当前应用，且完成消息仍只保存在裁剪的 UI 滚动区。此前删除翻页键没有改变这两个机制。

现在真实内联界面关闭鼠标报告；Windows 驱动启动时还主动关闭旧的鼠标报告模式，忽略残留鼠标事件。稳定的启动信息、用户消息、完成回复、工具结果、本地命令结果按显示顺序提交到终端主缓冲区并移出实时 DOM。只有未完成回复、工具和输入/菜单继续重绘。提交时移动内联起点、仅清除当前实时区及其下方，重置光标 bookkeeping；Windows 写入分块不超过 8192 字符，不截断正文。已完成的历史由终端自身滚动，跨应用启动保留，不需要应用转发滚轮。

Markdown 提交使用与实时界面一致的前景配色、❯/● 标记、普通代码块和耗时；不绘制独立背景或 dim 文字。临时思考正文不提交，取消时保留部分正文和实际取消说明。模型规范历史未裁剪或改变，UI 提交不等于上下文压缩、磁盘会话存储或恢复。原生历史受终端缓冲容量限制，旧版本未输出的隐藏内容无法自动补回。此前文档中的应用内部滚轮、首尾跳转行为由本次改动替代。
