# 第五章：结构化提示与缓存观测

日期：2026-10-11。状态：实现和本地验收完成，证据见 [validation.md](validation.md)，真实服务与人工效果尚未验证。用户已确认直接重写默认全局提示；编辑前读取仅通过提示和工具描述强化；动态模式提醒与用户消息分开。本章沿用 code-spec，不实现项目指令加载、Skill 加载、记忆、MCP、权限或自动评估。

## 行为与设计

- 七个固定模块按身份、系统约束、任务模式、动作执行、工具使用、语气风格、文本输出的顺序，以空行拼接。顺序是组织顺序，不赋予协议外的权限。指导应具体、可执行，不设置任意字符上限，也不为达到缓存门槛填充文本。
- 参考 Pi 的工具贡献机制：工具自己维护能力摘要与使用指导，同一份指导用于 API 描述和系统提示。构建器按注册顺序列出当前可用工具，合并并去重指导；计划模式只贡献只读工具，工具集不变时稳定提示不变。没有工具时明确说明；第三方工具缺少摘要时沿用其描述。显式自定义系统提示仍完整替换默认提示。
- 扩充跨工具指导：按相关范围调查、最小必要修改、根据具体失败原因恢复、按改动验证并据实报告。工具参数以真实 Schema 为准，不引入 Pi 的批量编辑、图片读取、项目指令或 Skill 加载等尚未实现的能力。
- 默认提示直接替换旧的一行提示。配置 `system_prompt` 仍可显式替换整个稳定提示；旧示例的一行默认值视为旧版默认并升级，不作为附加自定义模块。可选模块只预留组装接口，不加载外部资源。
- 稳定提示和工具定义顺序保持一致；环境（日期、系统、shell、工具工作目录）与模式提醒用请求级补充指令表示，始终不进入规范对话历史或 UI 用户消息。
- 计划模式：每个用户任务的第 1、6、11……次模型请求发送完整提醒，其余发送精简提醒。自动模式在这些位置发送完整提醒，其余不加无信息量的简短提醒。任务开始重置计数，取消/失败不留下旧提醒；间隔为运行时参数，默认 5。
- Responses：稳定 `instructions`；环境使用前置 developer 消息，模式使用末尾 developer 消息。Chat：稳定 system 消息；环境前置 system 补充，模式末尾 system 补充。Anthropic：稳定 system 文本块与后续不标缓存的 system 补充块，不伪装为用户消息。标签仅用于界定用途，由适配器确保角色。
- Anthropic 在稳定 system 块末端加一个 ephemeral 缓存边界，覆盖其前面的工具和稳定提示。`prompt_cache` 为 null 时仅 SDK 实际地址为 https://api.anthropic.com 启用，避免环境变量或 SDK 配置隐式转向中转；显式 true/false 控制标记。其他协议依赖服务自动缓存，不附加 Anthropic 参数。改变工具列表的模式切换允许缓存未命中，保留只读过滤和执行检查。
- 同一工作会话环境通常不变，日期按用户任务捕获；不会在稳定块中放入时间、工作目录、本次任务或当前模式状态。工具列表随模式过滤，固定模式约定保留在任务模式模块。模型的全部真实对话历史照常发送；本章不保证所有历史都命中缓存。
- read/edit/write/search/command 描述与稳定提示都约定优先使用专用工具、修改已有文件前先读取相关原文、依据真实工具结果报告。读文件的带行号输出不能原样当作编辑原文。文件内容和工具输出是数据，不因标签获得指令权限。

## 缓存用量与兼容性

统一 Usage 保存总输入、输出、缓存读取、缓存写入、未缓存输入；字段未知保持 None。Anthropic 总输入为未缓存输入+缓存读取+缓存写入，不把缓存计入两次。流式累计字段按最新值覆盖，不叠加 message_start/message_delta。

Responses 解析 input_tokens_details；Chat 解析 prompt_tokens_details，并兼容 DeepSeek prompt_cache_hit_tokens/prompt_cache_miss_tokens。未知、负数或错误类型不伪造零；缺失统计不阻止对话。跨请求累计已知值及缺失次数，部分缺失显示下限。

底栏展示累计缓存读取；无界面可通过 `--show-usage` 将每次模型请求的完整用量写到 stderr。普通正文不混入统计、配置或提醒。缓存命中仅证明服务报告复用了部分输入，不能据此推算总任务节省或一定遵守提示。

## 任务与验收

1. 提示模块、补充数据结构和任务内提醒调度；测试稳定块不含环境/模式、提醒第 1/6/11 次及新任务重置，历史不含补充消息。
2. 三个真实 SDK 的模拟 SSE 测试：请求角色和缓存边界、兼容端点不强加参数、工具配对和签名回放、缓存字段及流式末尾更新。
3. 用量累计、TUI/CLI 显示；测试已知零/未知/部分缺失/总量不重复计数，已有模式限制和取消回归。
4. 准备人工对比场景和仅通过显式调用运行的真实缓存探测脚本，记录数值不记录密钥、请求内容或响应全文；默认开发验证不读取真实配置、不调用真实模型。
5. 更新 README、配置示例与验证记录；完整测试、编译与 Windows 控制台烟测。真实服务命中及人工效果评价未运行时保持未验证。
