# MossCode 配色与模式底栏（已采用）

日期：2026-10-10。用户已批准配色方案，并要求底栏使用“自动模式 / 计划模式”。已应用到 `src/mosscode/appearance.py` 与 `tui.py`，没有更改 Agent 循环或工具执行行为。

沿用现有 Claude Code 风格布局、原生背景、正常前景亮度和浅绿 Logo。颜色用于定位操作和结果，不给整段回复着色，不添加色块背景。

| 颜色 | 用途 |
| --- | --- |
| 绿色 `#8bd5a6` | 成功勾号、读取/搜索工具名称，与 Logo 同色 |
| 蓝色 `#6fa8ff` | 工具参数中的路径、搜索表达式或短命令；Markdown 行内代码，包括明确标注的文件名 |
| 琥珀色 `#e3b95f` | Write/Edit/Shell 等改变环境的工具名称、运行中标记和阶段提示；不代表需要审批 |
| 红色 `#e87983` | 失败叉号、失败工具名称和“失败”标签 |

正文、工具输出、耗时、工作目录和其余状态文字保持终端正常前景。工具状态同时用 `●` / `✓` / `×` 和中文说明表示，不能只靠颜色区分。取消、未启动与计划拦截使用琥珀色 `!` 和“已取消 / 未执行”说明。错误详情仍清晰显示。

底栏始终显示绿色“自动模式”或琥珀色“计划模式”；运行时追加连接、思考、工具执行或输出阶段，阶段文字用琥珀色，轮次和耗时仍为正常前景。闲置和完成后不显示“就绪”。失败/取消/上限通知可以附加，但不替换当前模式；模式切换仍通过原有 `/plan`、`/do`。

当前应用了已批准的深色终端前景配色，仍只有原有文字主题，没有设置应用背景。浅色终端的强调色对比度尚未做适配；正文和普通辅助文字继续沿用终端前景。
